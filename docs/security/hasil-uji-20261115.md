## Temuan dan Rekomendasi

1. **CORS terlalu longgar (Sedang).** `config/cors.php` mengizinkan pola `#^https://.*\.trycloudflare\.com$#` dengan `supports_credentials => true`. Siapa pun dapat membuat quick tunnel dan memperoleh origin yang diizinkan. Rekomendasi: hapus pola trycloudflare, ganti dengan domain tetap.
2. **Snapshot biometrik di disk publik (Tinggi).** `ExamController` menyimpan ke `store('monitoring-snapshots', 'public')`; `/storage/` dilayani Nginx (403 pada direktori, 404 pada file yang tidak ada) sehingga file valid dapat diambil tanpa token. Rekomendasi: pindahkan ke disk privat dan sajikan lewat endpoint ber-otorisasi atau signed URL berumur pendek.
3. **Tidak ada HSTS (Sedang).** Tambahkan `Strict-Transport-Security: max-age=31536000` di Nginx atau Cloudflare.
4. **Header `X-Content-Type-Options` tidak ada (Rendah).** Tambahkan `nosniff`.
5. **Versi PHP terbaca (Rendah).** Sembunyikan `x-powered-by` (`expose_php=Off`).
6. **Batas login 1800/menit per IP (Sedang).** Nilai ini dipilih karena NAT sekolah, tetapi membuka ruang brute force. Rekomendasi: batasi per kombinasi IP+akun, bukan hanya IP.
